# FlowBoard

A modern team project-management dashboard built with React.

FlowBoard demonstrates professional-grade UI/UX design, complex state management without external libraries, and robust client-side architecture.

## Features

* **Advanced Drag & Drop:** Full drag-and-drop capability for reordering tasks within a Kanban board and reordering entire columns.
* **Complex Data Management:** Lifting state via Context to persist tasks, dynamic columns, tags, and users to LocalStorage.
* **Premium Dashboard:** Real-time analytics and statistics visualizing task progress.
* **Dark/Light Mode:** Seamless theme switching.
* **Responsive & Accessible:** Fully responsive across all devices and supporting `prefers-reduced-motion`.
* **Deep Linking & Command Palette:** Global search and URL state management for sharing exact tasks.
* **Markdown Parser:** Custom, zero-dependency Markdown renderer for task descriptions and comments.

## Tech Stack

* **Core:** React 19, JavaScript
* **Build Tool:** Vite
* **Routing:** React Router DOM (v7)
* **Styling:** Vanilla CSS, CSS Modules
* **Icons:** Lucide React

## Installation

```bash
git clone https://github.com/yourusername/flowboard.git
cd flowboard
npm install
npm run dev
```
